# Travel Recommendation

## Project Description

Travel Recommendation is a web-based project that helps users explore travel destinations and find suitable recommendations.

The project provides information about different destinations and allows users to interact with the website through a simple and user-friendly interface.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Home page
- Travel destination recommendations
- About page
- Contact page
- Responsive and user-friendly interface
- JavaScript-based interactions

## Project Structure

- `index.html` - Home page
- `about.html` - About page
- `contact.html` - Contact page
- `style.css` - Website styling
- `script.js` - JavaScript functionality
